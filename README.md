
# online Shopping Cart System

A JavaScript-based shopping cart project inspired by Amazon, developed to learn and practice JavaScript through hands-on development.

## Features
- Display and search products.
- Add, remove, and update cart items.
- Save cart data using Local Storage.
- Interactive checkout and delivery options.
- Place orders and view order history.
- Track orders.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Jasmine (Testing)

## Concepts Learned
- DOM Manipulation
- JavaScript Modules
- Object-Oriented Programming
- Classes, Inheritance and Polymorphism
- Promises and Async/Await
- API Integration and Error Handling
- Local Storage
- Automated Testing

## Purpose
Built as a hands-on learning project to improve JavaScript programming and frontend development skills.
